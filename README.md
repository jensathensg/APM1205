# APM1205
SA1 - Linear Models

## Project Overview
This project analyzes the Seoul Bike Sharing dataset using statistical methods and linear regression models in R.

## Objectives
- Explore the dataset using descriptive statistics and visualizations.
- Develop a simple linear regression model.
- Develop a multiple linear regression model.
- Perform statistical inference, ANOVA, and interaction analysis.
- Evaluate model assumptions and select an appropriate final model.

## Dataset
The dataset contains information about bike rentals and weather conditions in Seoul, South Korea.

## Software
R - Posit Cloud

## Repository Structure
- `data/` — dataset used in the analysis
- `code/` — R source code
- `output/figures/` — generated graphs
- `output/tables/` — generated statistical tables
- `report/` — final research report in PDF format
